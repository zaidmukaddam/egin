# Brand

## What it is
egin runs an AI agent written as a folder of plain files: instructions, tools, skills and settings.

## Who it's for
Developers who want a backend agent they own, on any model, without a framework to learn.

## Instead of
Agent frameworks that need a TypeScript or Python app around the agent, or a hosted agent builder.

## The one claim
An agent is a folder. One binary runs it, on any model.

## Proof
- Open source under MIT: github.com/zaidmukaddam/egin
- Install with `npx egin-ts@latest init my-agent` or `cargo install egin`
- Sessions survive a crash and resume from the last stored message

## Voice
Short and specific. Shows a command before explaining it. Dry, never hyped.

## Never say
- framework fatigue
- AI-powered
